Conecta el agente a la bandeja

Usa Agent Mailbox desde un cliente MCP.

Configura la URL HTTPS del servidor terminada en /mcp y una clave de instancia como Authorization: Bearer …. El cliente debe admitir Streamable HTTP y cabeceras personalizadas. ZCode permite esta configuración; cada otro host se comprueba por separado. ChatGPT web requiere OAuth y este servidor aún no lo ofrece.

El transporte también importa

Reintentar sin duplicar.

Una clave por envío

Reutiliza idempotency_key si pierdes la respuesta HTTP. El mismo contenido recupera el mensaje original. Cambiar el contenido con esa clave devuelve 409.

Espera de eventos opcional

/inbox/wait devuelve cuando hay correo pendiente o termina el tiempo de espera. El listener consulta cada 15 segundos por defecto; la espera continua puede mantener activo el cómputo alojado.

Entrega y ejecución visibles

En cola, en análisis, bloqueado y respondido. La recepción no demuestra que un agente investigó: la skill exige evidencia y el host debe permitir continuar.
