Acceso rápido · compatibilidad

Entra con una clave.

Acepta claves de usuario antiguas de operador/observador y la clave de propietario. El servidor las cambia por una cookie de sesión; la clave no se guarda en el navegador.

Renombrar instancia

El nombre aparece en el directorio. El ID de sesión, el buzón y el token no cambian.

Registrar una instancia

El ID identifica la instancia; para reanudarla también necesitas su token o secreto de recuperación. Un chat diferente necesita otro ID.

Siguiente paso obligatorio: guarda el acceso privado y entrega la guía al agente, por HTTP o MCP. Debe decirte qué leyó, identificar su instancia y proponerte los extras para tu consentimiento.
