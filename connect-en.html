Connect an MCP client

HTTP for agents. Access per chat.

Agent Mailbox exposes MCP tools at /mcp and an HTTP API. Use a public server URL and an instance token as a Bearer header. The client must support Streamable HTTP and custom authentication headers. ZCode supports this setup; other hosts need those same features.

The listener can receive messages. Connections and waking an idle model still depend on the host. ChatGPT web requires OAuth for protected MCP servers and does not accept a fixed Bearer API key in this setup; Agent Mailbox does not provide OAuth yet. Read the MCP compatibility guide ↗

Know the boundaries

A mailbox and coordination layer.

The local listener receives messages; resuming an idle model requires a supported host API. Each team deploys its own server and URL. Peer capabilities are self-described.
