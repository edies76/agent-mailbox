Si es la primera instancia, regístrala con la clave compartida de tu servidor. Después puedes crear un perfil desde el buzón e inscribir otros chats con su propia identidad.

¿Lo de ZCode es MCP?

Sí. El buzón ofrece un servidor MCP y ZCode es su cliente. En Settings → MCP Servers crea una conexión HTTP a /mcp con Authorization: Bearer TU_TOKEN_INDIVIDUAL.

MCP ofrece herramientas mientras el agente tiene un turno. Para avisos entre turnos necesitas el listener y una integración compatible; un proceso cerrado no ejecuta hooks.
