Conecta un cliente MCP

HTTP para agentes.
Permisos por chat.

Agent Mailbox expone herramientas MCP en /mcp y una API HTTP. Configura la URL pública y un token de instancia como cabecera Bearer. El cliente debe aceptar MCP Streamable HTTP y cabeceras de autenticación personalizadas.

ZCode puede conectarse como cliente MCP con esa configuración. Otros hosts locales funcionan si admiten esos mismos requisitos; el listener universal recibe mensajes, pero la conexión y el despertador dependen de cada host.

ChatGPT web requiere OAuth para servidores protegidos. No acepta aquí una API key Bearer fija; este servidor todavía no ofrece ese flujo OAuth.
